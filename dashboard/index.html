How the radar works

The value model

For every pre-token protocol the radar computes:

implied = TVL × comparable × growth × tenure × breadth
  • Comparable — the median market-cap / TVL of the live-token protocols in the same category (at least 3 of them, else the global median), clamped to 0.08–1.20. A lending protocol is priced the way lending protocols trade; a DEX the way DEXes trade.
  • Growth — 1 + (7-day TVL change, clamped to −50%…+150%) × 0.6.
  • Tenure — 0.80 + (days listed, capped at 4 years) / 4 years × 0.40. A protocol that has run longer with no token has more to launch.
  • Breadth — 1 + 0.02 per extra chain, up to 5 extra chains.

Nothing is hardcoded by name: the same four factors score every row, and the detail view shows each factor for the protocol you are reading, recomputed in this page from the same figures.

The watchlist

The snapshot’s watchlist is the floor, never the ceiling: protocols with at least $50M of TVL that record no token and are not a wrapped, staked or bridged product of a token that already trades. The board carries all 40 of them, plus every other rankable pre-token protocol below the floor — the early ones the radar exists to find.

The farm plan

Every row carries six steps: set up a fresh wallet, take the category’s main position with a stated amount of capital, repeat one qualifying action a week, hold long enough to be counted in more than one snapshot, check the protocol’s own points page before withdrawing, and keep a farm log with an exit plan. Each step states what it costs and how long it takes.

What this is not

The radar does not predict whether or when a token is issued. It prices what a launch would be worth if the protocol’s record stayed as it is, so a reader can decide where to spend their farming time. Data: a sealed DefiLlama snapshot, fetched once and frozen for every run.
